How We Built Career Campus

Career Campus was developed as a team project with a focus on creating a clear and consistent student experience.

Understand the Problem

We identified the difficulty students can face when exploring career options and understanding the skills required for them.

Design the Experience

We planned the user flow and created the interface design in Figma before developing the website.

Build the Website

We started converting the planned interface into separate website pages using HTML and CSS.

Continue Development

Future development can add interactive functionality, backend services, and database support.
